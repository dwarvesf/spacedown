# Welcome to Spacedown

You are reading this in Quick Look, not in a text editor. If you see headings, a table and typeset math instead of raw symbols, Spacedown is working. Press Space again to close.

## What it renders

| Feature | Looks like |
|---|---|
| Tables | Aligned columns with soft rules |
| Code | Highlighted, in a calm monospace |
| Math | Typeset, with no network needed |

Inline math sits in a sentence: the famous $E = mc^2$ renders as real notation.

> [!note] Callouts
> Obsidian-style callouts become styled blocks like this one.
