# Trademark policy

The code in this repository is licensed under the [AGPL-3.0](LICENSE) (releases up to and including v1.1.0 stay MIT, see [NOTICE](NOTICE)). That license covers the code. It does not cover the name **Spacedown** or the Spacedown icon, which identify the builds Console Labs publishes. Section 7(e) of the AGPL lets a project keep those out of the license, and this file says what you can do with them.

The aim is simple: anyone who downloads something called Spacedown gets the app Console Labs ships, not a build someone else changed.

## What you can do

- Build Spacedown from this source for your own use, changed or not. The AGPL allows that, including a build with the license check removed.
- Redistribute an official release unchanged, for example through a package manager, under the name Spacedown.
- Package the unchanged source for a package manager under the name Spacedown, with only the changes packaging needs.
- Say that your work is based on Spacedown, works with Spacedown, or is a fork of Spacedown, in plain words that do not suggest it is Spacedown.
- Use the name and icon to write about Spacedown, review it, teach it, or link to it.

## What needs a different name and icon

- A build with any other change, such as new or removed features, a removed license check, or other branding. Rename it and replace the icon before you share it.
- A product, company, domain, app store listing, or package name that people could take for Spacedown or for something made by Console Labs.
- Anything that suggests Console Labs endorses, sponsors, or supports your work when it does not.
- Selling copies, or builds with the paid features unlocked, under the Spacedown name.

## Questions

For anything this file does not cover, or to ask for permission, open an issue at [consolelabs/spacedown](https://github.com/consolelabs/spacedown/issues).
